The user wants to build a production-ready, enterprise-grade HRMS Admin Module for a company named Prakura HRMS.

**PRODUCT REQUIREMENTS:**
- **Backend:** Node.js + Express, Prisma ORM, PostgreSQL Database.
- **Frontend:** React + TailwindCSS, Redux Toolkit for state management.
- **Authentication:** JWT + bcrypt.
- **Validation:** Zod or Joi.
- **Security:** Helmet, Rate Limiting, CORS.
- **Deployment:** Docker ready, with CI/CD scripts.
- **Architecture:** SaaS-ready multi-tenant architecture.

**Modules to be built:**
1.  **Company Management:** Create/update profile, logo, working hours, timezone, financial year.
2.  **User Management:** CRUD for HR/Employee, role assignment, bulk upload, search, filter, pagination, export.
3.  **Department Management:** CRUD, assign department head.
4.  **Designation Management:** CRUD, assign salary band, link to department.
5.  **Leave Policy Management:** Create leave types, define limits, carry-forward rules, approval workflows.
6.  **Payroll Configuration:** Define salary components, tax slabs, payroll cycle, generate payslips (PDF), history.
7.  **Holiday Calendar:** Add/edit holidays, year-wise view.
8.  **Reports Dashboard:** Widgets for key metrics (employee count, leave, payroll), charts.
9.  **Audit & Security:** Login/activity logs, role permissions, IP whitelisting, manual backup.
10. **Employee Lifecycle Management:** Track complete employment journey including DOJ, department/role/designation history, salary changes, and exit details. Provide a timeline view for each employee.
11. **GitHub Actions:** A single workflow to deploy both frontend and backend.

**User's preferred language**: English
